## Implementation evidence

- `0019_first_class_15m_domain` is the single repository head. Its forward-only
  trigger rejects a result whose profile, mode, symbol, timeframe or boundary
  differs from its owning run. Existing rows were neither updated nor
  backfilled.
- The canonical 12-stage projection now treats 15m as an execution domain.
  Missing symbols receive deterministic projection-only `NOT_REACHED` states;
  counts remain SYMBOL counts and missing rows are not synthesized in storage.
- The 15m PAPER planner persists progressive geometry, RR, target/stop causal
  provenance and deterministic economic-gate inputs/output for both pass and
  reject paths.
- Final approval evaluates the actual persisted PAPER portfolio in the same
  transaction and persists measured exposure, limits, reason, policy and time.
- The readonly projection loads lifecycle state in one bounded set query and
  exposes explicit unknown values for historical rows.
- Desktop renders only server-supplied fields and consumes a derivative of the
  canonical server RU/EN catalogue.
