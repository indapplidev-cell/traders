The Computer Use connector available to this task exposed browser surfaces only
and no native-app binding. The acceptance therefore used an actual Windows Tk
root, real widgets, `Button.invoke()`, the Tk event loop, and the same two-config
offline engine; this is automated GUI execution, not a controller-only mock.
The reports-directory side effect was intercepted at the OS abstraction boundary
and proved to receive the exact run directory.
