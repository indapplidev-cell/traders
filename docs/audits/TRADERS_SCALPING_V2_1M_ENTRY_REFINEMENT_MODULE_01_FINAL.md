The module runs only after the existing `trade-5m-v2` selector winner. It can
wait, confirm, reject, expire, bypass, or fail the entry timing check; it cannot
create a candidate, change side, stop, target, quantity, risk, selector rank,
or portfolio authority. SHADOW never blocks the existing command path.

The durable identity includes profile, symbol, 5m boundary, candidate, final
approval, and persisted PAPER plan id. Terminal decisions are write-once.
Non-terminal SHADOW observations continue after the unchanged command path has
consumed the candidate, and expiry terminalizes the observation without
replaying a command.
