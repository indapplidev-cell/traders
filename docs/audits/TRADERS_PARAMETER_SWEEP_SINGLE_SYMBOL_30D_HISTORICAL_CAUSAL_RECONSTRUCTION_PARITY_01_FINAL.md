## Forensic and architecture result

The research-only adapter reads only the selected symbol and calls the current
authoritative `PipelineRunner`, `run_engine_analysis`, `SetupDetector`,
`StrategyFilter`, `RiskPolicy`, and scalping geometry evaluator. Its candle
repository filters every timeframe to data closed before the evaluated boundary.
No reconstructed row is written to PostgreSQL. Historical inputs that candles
cannot supply are explicit nulls with `CAUSAL_INPUT_UNAVAILABLE`; current live
book data is not backfilled into past boundaries.

The bounded 48-boundary overlap comparison produced exact setup type/status,
direction, strategy status, eligibility and strategy-score parity. It also
proved zero future-data and cross-symbol violations. Certification still fails:
historical spread/depth are missing, configured 10 bps fees differ from the
persisted account-commission 7.5 bps inputs, probability/EV parity is not proven,
terminal stages differ on 11 boundaries and rejection reasons differ on 24.
These are semantic decision-path differences, not serializer noise.

Because the decisive bounded comparison failed, running the remaining 2615
overlap boundaries could not turn the missing causal sources into evidence.
The certification gate therefore emitted `FAIL_NOT_CERTIFIED`, and
`HYBRID_30D_DATASET_MANIFEST.json` records `dataset_created=false`, zero hybrid
observations and `NOT_CREATED_PARITY_NOT_CERTIFIED`. No parameter search ran.

Generated evidence is stored in the ignored directory
`artifacts/scalping_v2_parameter_sweep/DOGEUSDT_30D_RECONSTRUCTION_PARITY_EVIDENCE_20260912/`
and was not committed.
