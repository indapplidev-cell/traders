the 5m request with HTTP 200, but the desktop transport reads only
`max_response_bytes + 1` and raises a contract-class error before parsing the
otherwise valid page. The same exact client path fails for 15m. A read-only
page-size-50 canary passes for both profiles, which narrows the defect to the
cross-repository page byte budget; it is evidence for remediation sizing, not
yet a production fix or full-export acceptance.
