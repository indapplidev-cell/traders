# Project Overview — traders-ml

## Назначение проекта

`traders-ml` — отдельный ML/analysis-сервис для проекта трейдинга.

Главная роль проекта сейчас:

> анализировать историю свечей и объяснимо определять состояние рынка.

Проект не должен сразу торговать, открывать сделки или утверждать наличие торгового преимущества.

## Новый главный приоритет

Текущий главный приоритет:

> BOOK-L1 Market Reader

Смысл:

> свечи → графико-технический анализ → тренд → структура рынка → режим рынка

Целевой результат первого слоя:

- `UP`
- `DOWN`
- `FLAT`
- `FLAT`
- `UNKNOWN`

## Что НЕ является текущей целью

Сейчас не является главной задачей:

- доказательство trading edge;
- запуск новых ML38.10 diagnostic stages;
- quick-quality rerun;
- heavy wrappers;
- подбор торговых сигналов;
- runtime-интеграция с исполнением сделок;
- LONG/SHORT рекомендации;
- изменение label policy;
- изменение class weights;
- изменение training objective.

## Главный принцип

Сначала система должна научиться читать рынок.

Только после этого можно переходить к торговым setup, edge validation и runtime-интеграции.
