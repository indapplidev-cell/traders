# Analysis Books

## Назначение книг

Книги используются не как готовые торговые сигналы, а как методологическая база для признаков анализа рынка.

Цель:

> перевести идеи технического и графического анализа в проверяемые признаки.

## Локальные книги

Файлы лежат локально:

```text
planning/books/japcandle_nison.pdf
planning/books/tech_analize_altunina.pdf
planning/books/tech_analize_schwager.pdf
```

PDF-файлы не добавляются в Git.

## japcandle_nison.pdf

Использовать для свечного контекста:

- doji;
- hammer-like candles;
- engulfing-like candles;
- strong body candle;
- long upper shadow;
- long lower shadow;
- continuation after candle pattern;
- confirmation / follow-through.

Важно:

> свечной паттерн без контекста не является торговым сигналом.

## tech_analize_altunina.pdf

Использовать для общей структуры технического анализа:

- тренд;
- уровни;
- поддержка;
- сопротивление;
- каналы;
- пробои;
- боковое движение.
- боковое движение.

## tech_analize_schwager.pdf

Использовать для практической логики анализа рынка:

- трендовая структура;
- ложные пробои;
- поведение цены около уровней;
- сила/слабость продолжения;
- риск переинтерпретации графика.

## Правило внедрения книг

Каждая идея из книги должна превращаться в проверяемый признак.

Нельзя внедрять правило вида:

> если паттерн X, значит покупать.

Можно внедрять правило вида:

> если есть паттерн X и после него есть follow-through, то добавить reason_code к текущему рыночному режиму.
